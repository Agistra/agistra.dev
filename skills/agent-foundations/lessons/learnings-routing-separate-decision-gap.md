# Learnings logged as memory-only prose

Going forward, a correction or recurring pattern gets a structured `.learnings/` entry as a matter of course, the same turn it's caught, rather than depending on the agent separately remembering to load `self-improving-agent` and decide to log it later — that separate-decision gap is exactly what let real trigger matches go straight into memory-only prose instead of a structured entry.
